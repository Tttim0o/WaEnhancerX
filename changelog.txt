[Feature: Hooking Method]
- Hooking method is a new feature that allows you to hook WhatsApp in different ways. 
- You can choose between 3 different hooking methods:
  - Balanced: Hooking some features on Startup, some features on demand (lazy injecting) for a balance between battery consumption and compatibility.
  - Maximum: Hooking every feature on Startup for maximum compatibility.
  - Lightweight (Pro): Hooking minimal features on Startup and more features on demand (lazy injecting) for minimum battery consumption.
  - Customized (Pro): You can customize the hooking method for each feature.


[Notes]
![Upcoming WhatsApp floating bottom bar](https://raw.githubusercontent.com/WaEnhancerX/WaEnhancerX/main/samples/upcoming-whatsapp-floating-bar.jpeg)

- Floating bar new features are inspired from WhatsApp's soon upcoming update of Floating bottom bar design.
- You can enjoy the same experience before WhatsApp even launches in beta. 
- Use these values to get a similar experince:
  - Horizontal Inner Padding: 5dp
  - Vertical Inner Padding: 0dp
  - Selector type: Oval
  - Selector Color: App Default or by your choice (with 30% opacity)
  - Hide Tab Labels (Icons Only): True
  - Icon Size: 26dp
  - Shadow: Enabled
  - Selected/Unselected Icon color: App Default or by your choice.
